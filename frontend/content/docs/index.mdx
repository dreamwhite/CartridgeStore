Welcome to the PRG32 documentation hub.

Use the area selector in the sidebar to move between the platform, the
Construction Kit, the Cartridge Store, computer architecture material, and the
textbook. These pages are curated copies of the documentation maintained in the
PRG32 repositories so the complete learning path is available in one place.

## Choose an area

- [Cartridge Store](/docs/store) for publishing, APIs, scores, metrics, and multiplayer.
- [PRG32 Platform](/docs/prg32) for hardware, runtime, ABI, tooling, and QEMU.
- [Construction Kit](/docs/construction-kit) for blocks, sprites, generated code, and tutorials.
- [Computer Architecture](/docs/architecture) for RISC-V and PRG32 course material.
- [Textbook](/docs/textbook) for the guided learning path and capstone projects.
