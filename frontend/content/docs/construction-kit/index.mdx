The Construction Kit is the visual classroom environment for creating PRG32
games. Follow the workflow from setup to a playable cartridge, then publish it
to the Store.

## Suggested path

1. [Set up the Construction Kit](./setup).
2. Learn the [Blockly vocabulary](./blockly) and [sprite editor](./sprite-editor).
3. Build a cartridge with [generated C and build hooks](./cartridge-build).
4. Inspect the [generated code](./generated-code).
5. [Publish the cartridge](./cartridge-store-publish).
6. Continue with the [tutorials](./tutorials).

The source repository is
[riscv-prg32/PRG32-Construction-Kit](https://github.com/riscv-prg32/PRG32-Construction-Kit).
