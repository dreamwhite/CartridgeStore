The PRG32 platform is the runtime and hardware foundation for cartridges. This
section collects the setup and compatibility material needed before building or
publishing a game.

## Start here

- [Getting started](./getting-started) — install the toolchain and prepare a target.
- [Tooling](./tooling) — understand the development tools and workflows.
- [QEMU](./qemu) — run cartridges without physical hardware.
- [Cartridge format](./cartridges) — inspect the platform cartridge model.

The source repository is [riscv-prg32/PRG32](https://github.com/riscv-prg32/PRG32).
